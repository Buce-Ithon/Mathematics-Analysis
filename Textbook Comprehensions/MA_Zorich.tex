\section{Multiple Integrals}
\subsection{The Riemann Integral over an $n$-Dimensional Interval}
\subsubsection{Comprehensions}
First, the definition of Riemann integral over $n$-dimention interval is simimiar (almost same) with $1$-dimension condition ($\int_{I}f(x)dx := \lim\limits_{\lambda(P)\to 0}\sigma(f,P,\xi)$),
$$\int_{I}f(x^1,\cdots,x^n)dx^1\cdots dx^n\ \text{or}\ \int\cdots\int_{I}f(x^1,\cdots,x^2)dx^1\cdots dx^n$$
Then, introduce the necessity condition of it ($f\in\mathcal{R}(I)\implies f\ \text{is bounded on}\ I$).
After that, book gives some properties (Lemmas) about the set of measure zero (same with $1$-dimension condition), and developes the Cantor Theorem (about uniform continuity of continuous functions on compact set).
At last, we're given 2 criterions (necessity and sufficiency) of the Riemann integral (Darboux Criterion, Lebesgue Criterion). 
\newline\newline
\fbox{\begin{minipage}{0.95\textwidth}
\begin{ex*}
Let $f:I\to\mathbb{R}$ is a continuous real-value function on $I\subset\mathbb{R}^{n-1}$, then it's graph is a set measure zero in $n$-dimension.
\end{ex*}
\end{minipage}}
\newline
\fbox{\begin{minipage}{0.95\textwidth}
\begin{lem}
/Development of Cantor Theorem/ If the relation $\omega(f;x) < w_0$ holds at each point of a compact set 
$K$ for the function $f : K \to \mathbb{R}$, then for every $\varepsilon > 0$ there exists $\delta > 0$ such 
that $\omega(f; U_{\delta}(x)) < w_0 + \varepsilon$ for each point $x \in K$.
\end{lem}
\end{minipage}}
\newline
\fbox{\begin{minipage}{0.95\textwidth}
\begin{thm}
(Lebesgue's criterion). $f \in \mathcal{R}(I) \Leftrightarrow (f$ is bounded on $I) \land$ 
$(f$ is continuous almost everywhere on $I)$.
\end{thm}
\end{minipage}}
\newline
\fbox{\begin{minipage}{0.95\textwidth}
\begin{thm}
(Darboux Criterion) $f\in\mathcal(I)\Leftrightarrow(f\ is\ bounded\ on\ I)\wedge(\underline{\mathcal{J}}=\overline{\mathcal{J}})$, 
where $\underline{\mathcal{J}}=\sup\limits_P s(f,P),\ \overline{\mathcal{J}}=\inf\limits_P S(f,P)$.
\end{thm}
\end{minipage}}

\subsubsection{Problems Sets}
\begin{prb}
\begin{enumerate}
  \item[a)] Show that a set of measure zero has no interior points.
  \item[b)] Show that not having interior points by no means guarantees that a set is of measure zero.
  \item[c)] Construct a set having measure zero whose closure is the entire space $\mathbb{R}^n$.
  \item[d)] A set $E \subset I$ is said to have content zero if for every $\varepsilon > 0$ it can be covered by a finite system of intervals $I_1, \ldots, I_k$ such that $\sum_{i=1}^k |I_i| < \varepsilon$. Is every bounded set of measure zero a set of content zero?
  \item[e)] Show that if a set $E \subset \mathbb{R}^n$ is the direct product $\mathbb{R} \times e$ of the line $\mathbb{R}$ and a set $e \subset \mathbb{R}^{n-1}$ of $(n-1)$-dimensional measure zero, then $E$ is a set of $n$-dimensional measure zero.
\end{enumerate}
\end{prb}
\fbox{\begin{minipage}{0.95\textwidth}
\begin{pf*}
\begin{enumerate}
  \item[a)] [Proof by contradiction] If $E$ has a point $x_0$ as an interior point, then there exists a ball $B(x_0, r)$ such that $B(x_0, r) \subset E$. Since the ball has positive measure, it follows that $E$ cannot have measure zero.
  \item[b)] [Counterexample] Consider the irrational numbers $\mathbb{R} \setminus \mathbb{Q}$, which have no interior points in $\mathbb{R}$ but are not of measure zero.
  \item[c)] /inspired by b)/ Consider the set $E = \mathbb{Q}^n$, the set of all points in $\mathbb{R}^n$ with rational coordinates. The closure of $E$ is $\mathbb{R}^n$, and $E$ has measure zero since it can be covered by countably many intervals whose total length can be made arbitrarily small.
  \item[d)] [Principle] No, since the Lebesgue measure zero set can be covered by at most countable intervals (which means measure $\mu=o(1)\cdot\mathcal{O}(1)$), while a set of content zero can be covered by a finite number of intervals (which means the content (also a kind of measure) sometimes is $\mathcal{O}(1)\cdot\mathcal{O}(1)$). [Example] The $\mathbb{Q}\cap[0,1]$ and Cantor set are sets of measure zero but none of content zero.
  \item[e)] From the construction of the product measure $\lambda_n$ (Lebesgue measure of $\mathbb{R}^n$) /Lemma1/ if $A \in B(\mathbb{R}^k)$ and $B \in B(\mathbb{R}^{n-k})$, ($0 < k < n$), then $\lambda_n(A \times B) = \lambda_k(A) \lambda_{n-k}(B)$. So here (using also that /Lemma2/ if $E_m \uparrow E$, $\lim_{m \to +\infty} \lambda_n(E_m) = \lambda_n(E)$) $\lambda_n(E) = \lambda_n(\mathbb{R} \times e)$ $= \lim_{m \to +\infty} \lambda_n((-m, m) \times e)$ 
  $= \lim_{m \to +\infty} \lambda_1((-m, m)) \times \lambda_{n-1}(e)$ $= \lim_{m \to +\infty} \lambda_1((-m, m)) \times 0$ $= 0$.
\end{enumerate}
\begin{nt*}
1. The proof of e) /Lemma2/ could found in \textit{Real and Complex Analysis} by Walter Rudin, Theorem 1.19(Page 16), based on the (positive) measure definition (countable additive of disjoint countable measurable sets).
\end{nt*}
\end{pf*}
\end{minipage}}
\newpage
\begin{prb}
\begin{enumerate}
  \item [a)] Construct the analogue of the Dirichlet function in $\mathbb{R}^{n}$ and show that a bounded function $f:I\to\mathbb{R}$ equal to zero at almost every point of the interval $I$ may still fail to belong to $\mathcal{R}(I)$.
  \item [b)] Show that if $f\in\mathcal{R}(I)$ and $f(x)=0$, at almost all points of the interval $I$, then $\int\limits_{I}f(x)\,{\rm d}x=0$.
\end{enumerate}
\end{prb}
\fbox{\begin{minipage}{0.95\textwidth}
\begin{pf*}
\begin{enumerate}
  \item[a)] [Counterexample] Consider $\mathcal{D}^n=\begin{cases} 1 & \text{ if } x\in\mathbb{Q}^n \\ 0 & \text{ if } x\in\mathbb{R}^n\backslash\mathbb{Q}^n \\\end{cases}$, the discontinuous set is $\mathcal{R}^n$.
  \item[b)] /by definition/ $\int_{I}f(x)dx=\lim\limits_{\lambda(P)\to 0}\sum\limits_{\xi_i\in P}f(\xi_i)\Delta(x_i)=\lim\limits_{\lambda(P)\to 0}\sum\limits_{\xi_i\in A\cap P}f(\xi_i)\Delta(x_i)+\lim\limits_{\lambda(P)\to 0}\sum\limits_{\xi_j\in B\cap P}f(\xi_j)\Delta(x_i)=\mathcal{O}(1)\cdot o(1)+o(1)\cdot\mathcal{O}(1)$, where $A=\{\cup[x_k,x_{k+1}]\subset P:\forall k,\ \exists \xi\in[x_k,x_{k+1}],\ s.t.\ f(\xi)\neq 0\}$ and $B=I\backslash A$. 
\end{enumerate}
\end{pf*}
\end{minipage}}

\subsection{The Integral over a Set}
\subsubsection{Comprehensions}
This part is not very long and mainly revolves around the concept of "admissible set". \\
First, the book introduces the concept (i.e. definition) of "admissible set" and some (operational) properties of it. Then, using a characteristic function $\chi_E$ of set $E$, we're 
given the definition of the integral over a set $E$ and the corresponding Lebesgue's Criterion (over "admissible set"). At last, the book also gives the Jordan  measure (or volume) 
of a bounded set $E$ (actually it's only well defined for "admissible set").
\newline\newline
\fbox{\begin{minipage}{0.95\textwidth}
\begin{df*}
An \underline{admissible set} is a \underline{bounded} set $E \subset \mathbb{R}^n$ s.t. $\partial E$ is \underline{measure zero} in sense of Lebesgue.
\end{df*}
\end{minipage}}
\newline
\fbox{\begin{minipage}{0.95\textwidth}
\begin{lem}
$\forall$ sets $E,\ E_1,\ E_2 \subset\mathbb{R}^n$, 
\begin{enumerate}
  \item[a)] $\partial E$ is the closed set on $\mathbb{R}^n$.
  \item[b)] $\partial (E_1\cup E_2),\ \partial (E_1\cap E_2),\ \partial (E_1\backslash E_2) \subset \partial E_1 \cup \partial E_2$.
  \item[c)] Finite union or intersection of admissible sets is still admissible set, the difference of admissible sets is still admissible set.
\end{enumerate}
\begin{nt*}
1. Generally, for infinite admissible sets, Lemma 2.2 c) is not true. \\
2. The boundary of admissible set is compact on $\mathbb{R}^n$ (closed and bounded).
\end{nt*}
\end{lem}
\end{minipage}}
\newline
\fbox{\begin{minipage}{0.95\textwidth}
\begin{df*}
The integral of $f$ over $E$ is given by $\int_{E} f(x) dx := \int_{\Gamma \supset E} f \chi_E(x) dx$, where $I$ is any interval containing $E$. If the integral exists, we say $f\in\mathcal{R}(E)$. \\
$\chi_E(x) = \begin{cases} 1 & x \in E \\ 0 & x \notin E \end{cases}$ is the characteristic function of set $E$ and $f_{\chi_E}(x) = \begin{cases} f(x) & x \in E \\ 0 & x \notin E \end{cases}$.
\end{df*}
\begin{nt*}
1. $\chi_E(x)$ is interrupted only on the boundary $\partial E$. The points of discontinuity of $f_{\chi_E}(x)$ are either points of discontinuity of $f$ on $E$, 
or the result of discontinuities of $\chi_E$, in which case they lie on $\partial E$.\\
2. $\forall I_1,\ I_2 \supset E$, integrals $\int_{I_1} f_{\chi_E}(x) dx$ and $\int_{I_2} f_{\chi_E}(x) dx$ either both exist (then values are equal) or both fail to exist.
\end{nt*}
\end{minipage}}
\newline
\fbox{\begin{minipage}{0.95\textwidth}
\begin{thm}
A function $f: E \to \mathbb{R}$ is integrable over an admissible set if and only if it is bounded and continuous at almost all points of $E$.
\end{thm}
\begin{nt*}
1. Compared with $f$, $f_{\chi_E}$ may have additional points of discontinuity only on the $\partial E$.
\end{nt*}
\end{minipage}}
\newline
\fbox{\begin{minipage}{0.95\textwidth}
\begin{df*}
The (Jordan) measure or content of a bounded set $E \subset \mathbb{R}^n$ is $\mu(E) := \int_E 1 \cdot dx = \int_{I\supset E} \chi_E(x) dx$, provided this Riemann integral exists.
\end{df*}
\begin{nt*}
1. Only admissible sets, are measurable in the sense of aformentioned definition.
\end{nt*}
\end{minipage}}
\newline
\fbox{\begin{minipage}{0.95\textwidth}
\textcolor{skycyan}{Comprehensions for Definition 3}(From Book.) \\
The geometric meaning of $\mu(E)$ (if $E$ is admissible) could be seen in following way:
$$\mu(E) = \int_{I\supset E} \chi_E(x) dx = \underline{\int}_{I\supset E} \chi_E(x) dx = \overline{\int}_{I\supset E} \chi_E(x) dx$$
Due to Darboux Criterion and Theorem, $\mu(E)$ is the common limit as $\lambda(P) \to 0$ of the volumes of polyhedra inscribed in 
and circumscribed about $E$, in agreement with the accepted idea of the volume of simple solids $E \subset \mathbb{R}^n$. \\
Why the $\mu(E)$ is called Jordan measure? \\
\fbox{\begin{minipage}{0.95\textwidth}
\begin{df*}
A set $E \subset \mathbb{R}^n$ is \underline{a set of measure zero in the sense of} \underline{Jordan} or a set of content zero if for every 
$\varepsilon > 0$ it can be covered by a finite system of intervals $I_1, \ldots, I_k$ s.t. $\sum_{i=1}^{k} |I_i| < \varepsilon$.
\end{df*}
\end{minipage}}
\newline
Compared with measure zero in the sense of Lebesgue, a requirement that the covering be finite appears here, shrinking the class of sets of Lebesgue measure zero. 
For example, the set of rational points is a set of measure zero in the sense of Lebesgue, but not in the sense of Jordan. \\
In order for the least upper bound of the contents of polyhedra inscribed in a bounded set $E$ to be the same as the greatest lower bound of the contents of polyhedra 
circumscribed about $E$ (and to serve as the measure $\mu(E)$ or content of $E$), it is obviously necessary and sufficient that the boundary $\partial E$ of $E$ have 
measure 0 in the sense of Jordan. That is the motivation for the following definition. \\
\fbox{\begin{minipage}{0.95\textwidth}
\begin{df*}
A set $E$ is Jordan-measurable if it is bounded and its boundary $\partial E$ has Jordan measure zero.
\end{df*}
\end{minipage}}
\newline
Hence, the class of Jordan-measurable subsets is precisely the class of admissible sets. That's the reason the measure $\mu(E)$ 
defined earlier can be called (and is called) the Jordan measure of the (Jordan-measurable) set $E$.
\end{minipage}}
